# 数字桌面工作台 · Digital Desktop

> 一个**单文件 HTML** 的个人数字工作台，双击即开，无需后端、无需联网、数据全部保存在本地浏览器（`localStorage`）。

## 功能一览

- **实时仪表盘**：日期 / 时钟 / 问候语 / 第几周 / 今日目标，随系统时间自动刷新。
- **待办清单**：增删改、标记完成、进度条统计，本地持久化。
- **灵感便签**：卡片墙式灵感收集，支持 `Ctrl/⌘ + Enter` 快速记录、置星、删除。
- **快捷入口**：常用网站一键直达，可自定义。
- **番茄钟**：25 分钟专注计时，结束有提示音（首次点击开始即激活声音）。
- **深色 / 浅色主题**：科技蓝 `#00aaff`，一键切换并记忆偏好。
- **数据导出 / 导入**：顶栏「导出 / 导入」按钮，把全部本地数据（待办 / 灵感 / 链接 / 昵称 / 目标 / 主题）存成 JSON 备份，换设备一键恢复。无后端、数据不出本机，便于手机 / 另一台电脑同步使用。
- **法考每日思维导图**：基于真实排期数据生成的可展开思维导图树（阶段 → 科目 → 每日任务），并内嵌孟献贵版每日真实思维导图（已应用勘误），点击日期查看当日详情。

## 使用方式

1. 直接双击 `index.html` 用浏览器打开即可使用。
2. 所有数据保存在本机浏览器，清空浏览器数据会丢失，建议定期备份。
3. 想换电脑使用：把 `index.html` 文件拷过去即可，内容互不共享（纯本地）。

## 技术说明

- 纯静态单文件，内联全部 CSS / JS，零外部依赖。
- 响应式三栏卡片布局，移动端自动单列。
- 法考排期来源：`法考每日学习计划.txt`（真实学习排期数据）。
- 每日思维导图来源：孟献贵版思维导图（已应用勘误），为本人已确认版本。

## 仓库说明 / 在线使用

- **在线网址（GitHub Pages）**：https://bucklee1025.github.io/digital-desktop/ —— 任何设备浏览器打开即用，无需下载文件。
- 本仓库为主文件 `index.html` 的源码与备份。因免费版 GitHub Pages 需公开仓库，本仓库已设为 **public**；文件内不含你的个人数据（待办/灵感等仅存于浏览器 localStorage），公开安全。
- 跨设备带数据：在任一设备打开网页点「导出」拿 JSON，到另一设备打开网页点「导入」即可恢复。注意 `file://` 本地文件与 `github.io` 网址是**不同源**，数据不互通，换源后用导出/导入迁移一次即可。
